## Como publicar no GitHub Pages

1. Crie um repositório público no GitHub (ex.: `glauco-guedes-portfolio`).
2. Envie o conteúdo da pasta `glauco-guedes-portfolio/` (`index.html`, `README.md` e a pasta `assets/`) para a raiz do repositório.
3. Em **Settings → Pages**, selecione a branch **`main`** e a pasta **`/ (root)`**, e salve.
